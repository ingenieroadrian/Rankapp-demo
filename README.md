# RankApp Demo

Maqueta estática para mostrar a un cliente el flujo completo de RankApp con datos ficticios:
inscripción y pago, sorteo del cuadro, programación en canchas, vista pública del celular y ranking.

- Un solo archivo: `index.html` (sin build, sin servidor, sin claves).
- Para verlo: abrir `index.html` en el navegador, o publicarlo en Vercel, Netlify o GitHub Pages.
- Para personalizarlo con el nombre de la liga, el torneo y los jugadores, editar el bloque
  "Configuración editable" al inicio del `<script>`.
- No guarda nada: "Reiniciar demo" vuelve al estado inicial.
